# Quick Reference / المرجع السريع

## 🇬🇧 English

### Essential Rules
- ✅ **22 working days** per year
- ✅ **Automatic weekends** (don't count)
- ✅ **Automatic holidays** (don't count)
- ✅ **Automatic calculation** of return date

### Usage in 3 Steps
1. 📅 **Choose** start date
2. 🔢 **Indicate** number of working days
3. 🧮 **Calculate** → Automatic return date

### Simple Example
**Request:** 5 days starting Monday
**Result:** 
- 5 working days (Mon-Fri)
- + 2 weekend days (Sat-Sun)
- = 7 calendar days
- **Return:** Following Monday

## 🇲🇦 العربية

### القواعد الأساسية
- ✅ **22 يوم عمل** في السنة
- ✅ **عطلات نهاية الأسبوع تلقائية** (لا تُحتسب)
- ✅ **الأعياد الرسمية تلقائية** (لا تُحتسب)
- ✅ **حساب تلقائي** لتاريخ العودة

### الاستخدام في 3 خطوات
1. 📅 **اختر** تاريخ البداية
2. 🔢 **حدد** عدد أيام العمل
3. 🧮 **احسب** → تاريخ العودة تلقائياً

### مثال بسيط
**الطلب:** 5 أيام ابتداءً من الاثنين
**النتيجة:**
- 5 أيام عمل (الاثنين-الجمعة)
- + يومين عطلة نهاية الأسبوع (السبت-الأحد)
- = 7 أيام تقويمية
- **العودة:** الاثنين التالي
