# App Store Documentation

Documentation for submitting your app to the Apple App Store.

- **[APP_STORE_SUBMISSION.md](APP_STORE_SUBMISSION.md)** - Complete step-by-step guide for App Store submission

## 🚀 Quick Start

1. **Prerequisites:**
   - Apple Developer Account ($99/year)
   - Xcode installed
   - App Store Connect access

2. **Quick Steps:**
   - Read [APP_STORE_SUBMISSION.md](APP_STORE_SUBMISSION.md)
   - Configure signing in Xcode
   - Build release archive
   - Upload to App Store Connect
   - Complete app listing
   - Submit for review

## 📋 Pre-Submission Checklist

- [ ] Apple Developer account active
- [ ] Bundle ID configured: `com.akhele.congecalculateur`
- [ ] App version set in `pubspec.yaml`
- [ ] App icon (1024x1024) ready
- [ ] Screenshots prepared
- [ ] Privacy Policy URL ready
- [ ] App Store Connect app created
- [ ] Build uploaded and processed
- [ ] All required information filled
